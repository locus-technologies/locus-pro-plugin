# Travel research

Normalize dates, time zones, airports, passenger counts, cabin, bags, and
flexibility before searching. Treat availability and prices as time-sensitive;
include the observation time and material restrictions when presenting an
option.

A search result or quote is not a booking. Do not purchase, reserve, or send
traveler data unless a separately exposed operation and the user's explicit
authorization cover that effect. Recheck the live contract and price before a
later run rather than freezing travel inventory in a saved Workflow.
